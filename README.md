# Park Pals

A simple top-down, free-roam game for toddlers. Open `index.html` in any browser (phone, tablet or desktop).

- Pick a friend (Mickey, Minnie, Donald, Goofy or Pluto); the others wander the park.
- **Joystick** (or arrow keys / WASD) to walk.
- **A** (or Z / Enter): pick flowers, pop balloons, wave at friends, splash in the pond, quack with ducks, ring the doorbell, eat a cookie, kick the ball. A green **A** marker shows what is nearby.
- **B** (or X): hop and dance.
- Collect the ⭐ stars; every 5 gets a party. 🔄 changes character, 🔊 mutes.

All art and sound are drawn/generated in code, with no external files.
