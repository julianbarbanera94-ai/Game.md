# Farmstead — Asset Integration Log

All runtime art is referenced by **manifest key** (`assets/manifest.json`), never by
hard-coded path. The manifest is generated by `tools/import_assets.py` from the
supplied phase ZIPs (which are not committed). Each entry records its source and a
`status`:

| status | meaning |
|---|---|
| `approved` | Supplied production sprite that matches the approved reference; used as-is (trimmed, edge-cleaned). |
| `temporary-reference-derived` | Sliced from a *reference board*. Visually on-style but low-res (~80 px) with keyed backgrounds. **Must be replaced** by properly exported sprites. |
| `placeholder` | Supplied placeholder (audio). Replace before release. |

Regenerate (each pack extracted into its own folder):

```bash
python3 -I tools/import_assets.py --phase1 <p1> --phase2 <p2> --phase3 <p3>
```

Visual benchmark: `docs/reference/approved_starting_area_reference.jpg`.

Notes:
- `reference_tiles/*` are illustrated vignettes with ragged transparent edges, **not seamless tiles**. They are used as texture-stamp sources for the painted ground (`src/render/terrain.js`).
- Some foliage had dark magenta key spill on edges; cleaned at import (counts recorded in the manifest notes).
- The `preview/index.html` prototype in the pack was reviewed but not used; the game is a separate implementation.

## Phase 3 — Farming & crops (reference boards only)

The README states these are **not** production sprites. Because Phase 1's crop
sprites fail the art check, the milestone uses *temporary* slices:

- `plot.<crop>_<stage>` — 8 crops × planted/sprout/growing1/growing2/mature/ready/ready_alt, each a soil plot with the crop (from `crop_growth_stages_all.png`), masked to a rounded rect.
- `plot.soil_tilled`, `plot.soil_harvested` — empty tilled soil.
- `plot.soil_dry` — from `soil_variations.png` (resized to the crop-cell footprint; slight non-uniform scale). Shown pale as **untilled** ground.
- `icon.seed_<crop>`, `icon.produce_<crop>`, `icon.tool_{hoe,watering_can,basket}` — HUD/shop icons, background keyed out.
- Wet soil is a runtime darkening of soil pixels (no wet sprites supplied).

**Production assets still required:** isolated transparent crop sprites per stage
(separate from the soil), wet/dry/hoed soil tiles at full resolution, seed/produce
icons at ≥128 px, multi-frame tool animations.

## Other gaps found during integration
- No **vertical fence run** sprite: garden side fences use the left post cropped from `fence_segment.png`.
- No detailed **NPC** sprites (Phase 7 is reference-only), so the market is run from the stall itself for now.
- HUD icons in the v1 pack are flat; the HUD uses CSS panels, painted Phase 3 icons and two small inline SVG glyphs (journal, menu).
- VFX (dirt, water, sparkle particles) are simple procedural particles pending Phase 10 effects art.

## Phase 4 — Buildings & expansion (reference panels only)

The pack README says the panels are **not** isolated sprites. They were cut out by
`tools/import_assets.py --phase4` (cream background keyed out; level columns split at
the label separators; upscaled 2× with Lanczos) and are marked
`temporary-reference-derived`:

| Keys | Source panel | Used for |
|---|---|---|
| `building4.{house,well,tool_shed,market_stall,storage_shed}_l{1,2,3}` | `01_building_upgrades/*` | Levels 2–3 of each building (level 1 keeps the sharper Phase 1 sprite); storage shed levels 1–3 |
| `building4.construction_stage{1..5}` | `02_construction_stages` | Stages 1–4 shown while any building is under construction (stage 5 is a finished red barn, so it isn't used) |
| `prop.{scarecrow,bench,flower_crate,berry_crate,hay_bales,lantern_post,trough}` | `05_decorations_and_props` | Placeable decorations |
| `interior.{house,tool_shed,barn,coop}` | `03_building_interiors` | **Not loaded.** Kept as the "before" reference; the cottage is now built from layers (`src/render/interiorArt.js`) |
| `interior_prop.{workbench,barrel,water_barrel,crate}` | Phase 1/2 crisp sprites | Indoor props at native size with the outdoor grass base keyed out (`import_assets.py --interior`) |

Not used:
- `07_npc_workers`: figures are about 25 px tall, far too small for the 84 px player.
- `04_fences_walls_gates` and `06_terrain_expansion`: not needed for this milestone.
- `08_animals_and_vehicles_reference`: belongs to Phases 5–6.

**Production assets still required for Phase 4:** full-resolution transparent
exports of every building level with a shared footprint/anchor, construction stages
for non-barn buildings, a full-resolution cottage interior with separate furniture,
and decoration sprites at ≥128 px.
